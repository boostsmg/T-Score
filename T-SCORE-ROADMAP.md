# T-Score Product Roadmap

## Phase 1 — Trust Core
- Server-owned 0–100 Trust Score.
- Verification states: profile photo, email, phone, identity, address, selfie/liveness.
- Reputation states: account age, successful deals, reviews, account standing.
- Public profile exposes only score, badge and verification booleans; raw CNIC/address stay private.
- Score changes must be auditable and never editable by the mobile client.

## Phase 2 — Deals
- Start Deal from chat.
- Buyer/seller roles, amount/currency, terms, deadline.
- Requested → Accepted → In Progress → Delivered → Completed/Cancelled/Disputed.
- Immutable deal event history.

## Phase 3 — Reviews & Disputes
- Review only after a completed deal.
- Buyer/seller ratings and public review history.
- Dispute workflow, evidence attachments, admin resolution.
- Reputation penalties only from verified outcomes.

## Phase 4 — Verification
- Email OTP, phone OTP.
- Profile photo review.
- CNIC/National ID + selfie/liveness.
- Address verification.
- Sensitive documents encrypted/private; public profile shows badges only.

## Phase 5 — Messenger Polish
- Replies, forwarding, edit/delete, voice notes, media/files.
- Read/delivery state, typing, presence, search, pinning.
- Better chat list/message UI and notifications.

## Phase 6 — Safety & Admin
- Reports, blocks, suspensions, fraud signals.
- Verification review queue, disputes, user/deal/review moderation.
- Admin audit logs and statistics.

## Phase 7 — Advanced Communication
- Groups/communities.
- Voice/video calls.
- Multi-device/web client improvements.

Current focus: Phase 1.
