# T-Score: Deal with Confidence

T-Score is a self-hosted messaging and trust/deal platform being built on an open-source Tinode foundation.

## Repository layout

- `server/` — Tinode messaging server base
- `android/` — Tinode Android client base
- `web/` — Tinode web client base

## Branding

Product name: **T-Score**
Tagline: **Deal with Confidence**

Product-specific branding, package IDs, UI, trust/deal features, infrastructure configuration and deployment are maintained in this repository.

## Upstream attribution and licenses

Initial foundation incorporates open-source components from:

- https://github.com/tinode/chat
- https://github.com/tinode/tindroid
- https://github.com/tinode/webapp

Original license files and notices are retained inside each imported component. Distribution and modification must comply with the applicable upstream licenses.
